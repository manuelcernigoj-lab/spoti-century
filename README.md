# spoti-century

Exploratory analysis of ~600k Spotify tracks released between 1921 and 2020,
combining audio feature analysis, temporal trend analysis, and unsupervised clustering
to explore how music has evolved over a century.

## Notebooks

The notebooks are designed to run **in sequence**. `00_cleaning.ipynb` must be executed
first — it generates `data/processed/tracks_clean.parquet`, which all downstream
notebooks load directly. No cleaning is repeated across notebooks.

| Notebook | Purpose | Key output |
|----------|---------|-----------|
| `00_cleaning.ipynb` | Null handling, deduplication, date parsing, duration conversion, key/mode labeling, outlier removal (IQR + Log+IQR), noise filtering | `tracks_clean.parquet` |
| `01_eda.ipynb` | Univariate distributions, before/after cleaning comparison, categorical feature overview | Dataset overview |
| `02_temporal_analysis.ipynb` | Feature trends 1921–2020, Loudness War scatter analysis, valence anomaly, mode and key evolution by decade | Temporal findings |
| `03_clustering.ipynb` | Track-level correlation analysis, PCA feature compression, stratified sampling, K-Means (k=4 final, k=6 secondary), liveness ablation | Macro-genre clusters |

## Setup & Installation

**1. Clone the repository**
```sh
git clone https://github.com/your-username/spoti-century.git
cd spoti-century
```

**2. Create and activate a virtual environment**
```sh
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

**3. Install dependencies**
```sh
pip install -r requirements.txt
```

**4. Download the data**

Download `tracks.csv` and `artists.csv` from
[Kaggle](https://www.kaggle.com/datasets/yamaerenay/spotify-dataset-19212020-600k-tracks/data)
and place them in `data/kaggle2/`.

**5. Run the notebooks in order**

Start with `00_cleaning.ipynb` to generate the parquet file,
then proceed through `01` → `02` → `03`.

## Key Findings

**Loudness War**
Loudness increased monotonically from the 1950s onward — likely a causal driver
of correlated trends: energy up, acousticness down, instrumentalness down.
The strongest inflection point occurs around 1953, marking the adoption of
electric amplification and magnetic tape recording.

**Valence anomaly**
Valence follows a W-shaped trajectory across the century, with a steady decline
from the 1980s to 2020. Critically, both Major and Minor key tracks follow
the same pattern — the decline is systemic, not explained by a compositional
shift toward minor keys.

**Key distribution**
Natural keys (C, G, D) dominate due to instrument ergonomics. A shift from F
toward A in the 1960s–70s reflects electric guitar adoption. A C# resurgence
near 2020 is consistent with DAW-based production removing physical key constraints.

**Clustering — the DNA of genres**
K-Means on audio features (k=4, without year or liveness) produces four
musically coherent macro-genre archetypes:

| Cluster | Label | Key signature |
|---------|-------|---------------|
| 0 | Soft Pop / R&B | High valence, moderate energy |
| 1 | Dance-Pop / Electronic | High danceability, loud, high energy |
| 2 | Classical / Ambient | High acousticness, high instrumentalness |
| 3 | Hip-Hop / Rap | High speechiness, low acousticness |

## Methodological Notes

**Parquet over CSV**
All notebooks downstream of cleaning load `tracks_clean.parquet` rather than CSV.
Parquet preserves dtypes across sessions (including lists, datetimes, and categoricals),
eliminating the need to repeat cleaning steps in each notebook.

**Ecological fallacy**
Correlations computed on yearly means dramatically overstate track-level relationships
(e.g. `energy ↔ acousticness`: −1.0 on yearly means vs −0.71 at track level).
All feature decisions in the clustering notebook are based on track-level correlations.

**Stratified sampling**
The dataset is temporally imbalanced — the 2000–2020 period dominates.
Clustering uses a 60,000-track stratified sample by year to prevent modern-era
content from suppressing historical genres.

**Liveness ablation**
Removing `liveness` from the clustering feature set improved silhouette scores
across all values of k without changing cluster archetypes, confirming it
was adding noise rather than signal.
